Personvernerklæring

Vi bruker ikke informasjonskapsler, analyseverktøy eller sporingsskript fra tredjeparter. De eneste personopplysningene vi mottar direkte, er opplysninger du velger å sende oss på e-post.

1. Behandlingsansvarlig

R&D Nordic er behandlingsansvarlig for personopplysningene som er omtalt her. Kontakt oss på contact@rdnordic.com.

2. Hvilke personopplysninger vi behandler

  • E-postkorrespondanse: e-postadresse, navn hvis oppgitt, meldingsinnhold og eventuelle vedlegg.
  • Tekniske driftslogger: GitHub Pages kan behandle IP-adresse og relatert teknisk metadata for sikkerhet og misbruksforebygging.

3. Formål og behandlingsgrunnlag (GDPR art. 6)

Vi behandler personopplysninger for å svare på henvendelser, følge opp dialog før en mulig avtale og ta vare på nødvendige kommunikasjonslogger.

  • Art. 6(1)(b): behandling som er nødvendig for å gjennomføre tiltak på din forespørsel før avtaleinngåelse.
  • Art. 6(1)(f): vår berettigede interesse i å svare på meldinger og dokumentere forretningskommunikasjon.

4. Databehandlere og overføringer

Vi bruker følgende leverandører:

  • Proton Mail for e-posttjenester.
  • GitHub Pages for hosting av nettstedet.

Noe behandling kan innebære overføring utenfor EØS eller Storbritannia. I så fall brukes leverandørenes avtalte overføringsgrunnlag, for eksempel EUs standard personvernbestemmelser, slik leverandøren beskriver i sin personverndokumentasjon.

5. Lagringstid

Vi lagrer henvendelser i inntil tolv måneder og sletter dem deretter, med mindre loven krever lengre oppbevaring. Du kan be om sletting tidligere når det er aktuelt.

6. Dine rettigheter

Du kan be om innsyn, retting, sletting, begrensning og dataportabilitet. Du kan også protestere mot behandling som bygger på berettiget interesse og klage til Datatilsynet.

7. Kontakt om personvern

For spørsmål om personvern eller for å bruke rettighetene dine, send e-post til contact@rdnordic.com. Vi kan be om nok informasjon til å bekrefte identiteten din før vi behandler forespørselen.
